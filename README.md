# BySS для компьютера

Браузер без рекламы и слежки — версия для Windows (тот же движок Chromium, что и в Chrome).

**Скачать:** [BySS-Setup.exe](https://github.com/andrewu1337-hub/BySS-PC/releases/latest/download/BySS-Setup.exe)

- блокировка рекламы и трекеров (EasyList, EasyPrivacy, RU AdList, Peter Lowe);
- главная с погодой, двумя поисками, конвертером валют (курсы — ExchangeRate-API) и сайтами на плитках;
- режимы BySS — вкладки без следов, можно несколько сразу;
- перевод страниц прямо на сайте (работает и на YouTube), поиск по странице;
- скриншоты: видимая часть, вся страница или выделенная область (Ctrl+Shift+S);
- скачанные файлы — отдельная страница (Ctrl+J);
- в меню ⋮ — быстрый переключатель рекламы и слежки для открытого сайта;
- выбор поисковика прямо в адресной строке, окно запоминает размер и «на весь экран»;
- установщик: можно выбрать папку и решить, добавлять ли «мои сайты» на главную;
- обновления прямо из меню ⋮ → «Обновить браузер».

Windows может предупредить «Неизвестный издатель» — нажмите «Подробнее» → «Выполнить в любом случае».
